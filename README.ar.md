# Git Architecture Diagram

أداة مفتوحة المصدر لفهم مستودعات GitHub عبر **Mermaid**، و**Mind Map**، و**Repository Tree**، وتقرير **Genius** مرتبط بمصادره.

تطوير **أمين سعود ابن البشير — Amine Saoud ibn al-Bashir**، حساب [ProAmineOfficial](https://github.com/ProAmineOfficial). الترخيص: MIT.

## التشغيل

تحتاج إلى Node.js بالإصدار 22.12 أو أحدث:

```bash
git clone https://github.com/ProAmineOfficial/GitArchitectureDiagram.git
cd GitArchitectureDiagram
npm ci
npm start
```

افتح `http://localhost:3000`، ثم ألصق رابط المستودع. جرّب `ProAmineOfficial/NanoKit-ESP32`. لفحص مثال محدد، اختر المجلد `examples_on_platformio/ultrasonic_distance` في Options.

## الوظائف

- شجرة ملفات قابلة للبحث والتوسيع، مع تمييز الملفات المقروءة عن الملفات المدرجة فقط.
- مخطط Mermaid لعلاقات الاستيراد والتضمين الموجودة في المصدر، وخريطة ذهنية لبنية المجلدات.
- عرض مخططات Mermaid التي كتبها صاحب المستودع في التوثيق، بما فيها مخططات العمل والتوصيلات إن كانت ضمن الملفات المقروءة.
- تقرير Genius يوضح التغطية، وملفات البداية المحتملة، والتقنيات المستدل عليها من ملفات الإعداد، وحالة وجود التوثيق.
- معاينة المصدر وروابط مثبتة على نسخة محددة من الكود، وبحث في الأسطر المقروءة.
- تكبير وتحريك وملء الشاشة، وتحرير Mermaid للمعاينة، وتصدير Mermaid وSVG وPNG وحزمة `.genius`.
- تفسير اختياري بالذكاء الاصطناعي بعد إدخال مفتاح OpenAI ومعرّف نموذج وتفعيل الخيار صراحةً. التحليل البنيوي لا يحتاج نموذجًا.

## تغيير عنوان GitHub

المسار `/OWNER/REPOSITORY` جاهز داخل التطبيق. بعد نشره على خادم وربط نطاق، يصبح استبدال `github.com` بنطاقك كافيًا لبدء التحليل. **المستودع وحده لا يوفر موقعًا مستضافًا أو نطاقًا عامًا**. انظر [تعليمات النشر](docs/DEPLOYMENT.md).

## حدود واضحة

هذه نسخة عملية أولى. لا تنفذ الكود ولا تتحقق من عمل الأجهزة. استخراج العلاقات يدعم أنماطًا شائعة في JavaScript/TypeScript وPython وC/C++، وليس جميع اللغات والتصرفات الديناميكية. شجرة الملفات تعمل لبقية المستودعات ضمن حدود GitHub والموارد، ويمكن إضافة تفسير AI اختياري.

يقرأ التحليل افتراضيًا 32 ملفًا، ويمكن تغيير العدد حتى 120. يعرض التقرير الملفات التي لم تُقرأ، والمخططات المحدودة للمعاينة، وأي فشل في الجلب. العلاقات المستخرجة من الكود منفصلة عن المخططات التوثيقية وعن استنتاجات النموذج. لا يُدّعى أن فحص وجود ملف أو صلاحية مرجع AI يثبت صحة المشروع.

رموز الوصول لا تُحفظ في تخزين المتصفح ولا في ملفات المشروع. للمستودعات الخاصة استخدم رمز قراءة خاصًا بك، وشغّل الأداة على خادم تثق به. تفعيل AI يرسل مقتطفات من الكود إلى مزوده وقد يترتب عليه استهلاك مدفوع. [تفاصيل الخصوصية](docs/PRIVACY.md).

لإنشاء توثيق فعلي من سطر الأوامر:

```bash
npm run analyze -- ProAmineOfficial/NanoKit-ESP32 --scope examples_on_platformio/ultrasonic_distance --max-files 24 --output .genius
```

تحتوي الملفات الناتجة على إصدار Genius، ووقت التوليد، ونسخة الكود، والتغطية، وأدلة العلاقات. لا يكتب التطبيق أي تعديل في المستودع الذي تحلله.
